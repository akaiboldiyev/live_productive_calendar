GOAL DOTS — DIAGNOSTICS

1. Connect the phone by USB and unlock it.
2. Double-click START_GOALDOTS_DIAGNOSTICS.bat.
3. Reproduce the wallpaper issue.
4. Press Ctrl+C in the black window when finished.
5. Send the newest diagnostics_YYYYMMDD_HHMMSS folder.

No PowerShell, cd command, PATH setup, or ADB commands are needed.
